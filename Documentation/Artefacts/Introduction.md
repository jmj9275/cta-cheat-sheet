# Introduction

## Description

The objective of this section is to provide the overall context of the scenario in order to tell a story.

It should contain the following information:
* Name of the company
* Customer scope (B2B, B2C...)
* Product scope
* Service scope
* Location (countries)
* Nb of regions
* Nb of offices
* highlight the pain points of the company in the given scenario
